Template

Documentation page anatomy

The reference template keeps stable deep links on desktop and mobile. Nested navigation can be collapsed without removing the section link itself.

Desktop: sticky left navigation stays visible while the main document scrolls.

Mobile: the same navigation becomes an off-canvas drawer.

Nested sections: the section label jumps to content while the adjacent chevron only expands or collapses its children.

Live references: component examples come from the same HTML files you edit directly.

Radius

The token values remain aligned with the original system. The audit makes --radius-sm (6px) the default component radius; 12px is reserved for deliberately larger surfaces.

TokenValueUse
--radius-sm6pxPanels, inputs, buttons, tiles, menus, previews

Editor panels size hex, opacity, and weight with .combo at --control-height-sm. The .input--* utilities are for a lone field, not a substitute for that combo.

Authoring

Single-source component pattern

Keep each component editable as a normal HTML file. The index references it instead of duplicating its markup.

<!-- place-card.html: edit this file directly -->
<link rel="stylesheet" href="global.css">
...
<script src="component-embed.js"></script>

<!-- index.html: render that same source file -->
<iframe
  class="component-preview"
  src="place-card.html?embed=1"
  title="Place Card live component reference">
</iframe>

component-embed.js only changes presentation when the file is embedded: it hides demo-page chrome, reports its content height to the index, and receives the documentation theme. It does not contain component markup.

Authoring

Responsive behavior

The information architecture remains the same across breakpoints, including every component anchor.

  • Desktop keeps the navigation sticky and independently scrollable.
  • Below 860px, navigation becomes an off-canvas drawer with overlay and Escape-key support.
  • Nested navigation trees can collapse independently from the content sections they link to.
  • Design Tokens and Map editor can also collapse in the document; following a deep link reopens the relevant section automatically.
  • Component iframes resize to their own content to avoid nested scrolling.
